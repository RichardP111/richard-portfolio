# Richard Pu - Portfolio

The source code for my personal engineering portfolio.

The website highlights my work in embedded systems, AI, hardware, and software, including:

- Smart Chess Board
- AI Red Light, Green Light
- BenumZombs
- Truck Game
- Memory Matrix

Visit the website for the full project descriptions, media, source-code links, and contact details.

## Run locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Built with

Next.js, React, TypeScript, Tailwind CSS, Framer Motion, and Vercel Analytics.
